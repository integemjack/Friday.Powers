# friday-opencode 用到的第三方代码

静态链接进 friday-opencode 的 Rust 包（都在 crates.io，许可证见各包）：

- serde_json（MIT / Apache-2.0）
- ureq、ureq-proto（MIT / Apache-2.0）
- sha2、digest 等 RustCrypto 包（MIT / Apache-2.0）
- base64（MIT / Apache-2.0）

friday-opencode 不带 OpenCode 本身：它连本机已经装好的 OpenCode（https://opencode.ai，MIT）。
